# 도메인 등록 (AWS Route 53)

> **작업자가 직접 수행한다.** 로그인·결제·등록자 정보 입력이 필요하다.
> 이 문서는 무엇을 왜 고르는지와 절차, 그리고 놓치기 쉬운 지점을 정리한 것이다.

관련: [ADR-002 등록 도메인 2개](decisions/ADR-002-two-registered-domains.md) · [setup.md](setup.md) · [worklog.md](worklog.md)

---

## 1. 무엇을 사는가

**등록 도메인 2개.** 서브도메인으로는 실험이 성립하지 않는다.

| 역할 | 호스트 | 성격 |
|---|---|---|
| 광고주 측 | `lp.` · `app.` | first-party. 사용자가 방문하는 곳 |
| 추적 측 | `api.` | **third-party.** 크로스사이트 요청을 받는 곳 |

---

## 2. TLD 선택 — 여기서 실험이 성패가 갈린다

싼 TLD를 고르고 싶어지지만, **이 프로젝트에서는 TLD가 실험 변수다.**

### 문제

`.click` `.xyz` `.top` `.link` `.site` 같은 저가 TLD는 스팸·피싱 비율이 높아 **TLD 단위로 차단되는 경우가 많다.**

| 차단 주체 | 근거 |
|---|---|
| 광고 차단기(uBlock 등) | 필터 목록에 저가 TLD 패턴이 통째로 들어가는 경우가 있다 |
| 기업·학교 DNS | 신규·저가 TLD를 기본 차단하는 정책이 흔하다 |
| 브라우저 트래커 목록 | 추적 도메인처럼 보이는 이름 + 저가 TLD 조합은 표적이 된다 |
| 메일 서버 | ICANN 인증 메일이 스팸함으로 갈 확률이 올라간다 |

### 왜 이게 치명적인가

이 프로젝트의 목적은 **브라우저가 크로스사이트 쿠키를 어떻게 다루는지 측정하는 것**이다.
그런데 TLD 평판 때문에 요청이 막히면 결과가 오염된다.

> `api.<track>` 요청이 실패했을 때
> **`SameSite` 때문인지, TLD 차단 때문인지 구분할 수 없다.**
> 측정 도구가 측정 대상에 오염되는 셈이고, `failure-scenarios.md`의 모든 표가 못 쓰게 된다.

### 결정

| | 선택 | 이유 |
|---|---|---|
| **추적 도메인** | **`.com` (또는 `.net`)** | 평판이 중립적이어야 한다. 타협 불가 |
| **광고주 도메인** | **`.com` 권장** | 대조군이므로 조건을 같게 둔다. 한쪽만 저가 TLD면 비교가 흐려진다 |

> **여기서 아끼면 프로젝트가 무의미해진다.** 등록 도메인 2개를 사는 이유 자체가 실험이고, 그 실험을 오염시키는 절약은 절약이 아니다.

### 이름 짓기

- 두 도메인이 **서로 무관해 보여야** 한다 — 현실의 광고주와 추적 사업자가 그렇듯이
- 추적 쪽은 `track`·`tag`·`pixel` 같은 노골적인 단어를 피한다. **차단 목록의 휴리스틱에 걸린다**
- 예: `toonlab-<suffix>.com` (광고주) / `abridge-<suffix>.com` (추적)

## 3. 비용 — 잊기 쉬운 항목이 있다

| 항목 | 비용 | 비고 |
|---|---|---|
| 도메인 등록 | **콘솔 검색 시 표시됨** | 2026-07-01자로 약 267개 TLD 가격이 개정됐다. `.com`·`.org`는 $1~2 인상 |
| **호스팅 영역(Hosted Zone)** | **$0.50 / 영역 / 월** | 도메인 등록 시 **자동 생성**된다. 2개면 월 $1, 연 $12 |
| DNS 질의 | $0.40 / 100만 건 | 이 프로젝트 규모에선 사실상 0 |
| WHOIS 프라이버시 | **무료** | Route 53은 기본 제공 |

> **호스팅 영역 비용이 도메인 값에 가려 잘 안 보인다.** 2개면 연 $12가 별도로 나간다.
> 프로젝트가 끝나고 도메인을 놀릴 거라면 호스팅 영역만 삭제해도 과금이 멈춘다.

**대안**: Route 53에 등록하되 DNS는 다른 곳(무료 DNS)에 두면 호스팅 영역 비용을 없앨 수 있다. 네임서버만 바꾸면 된다. 다만 EC2와 콘솔이 한곳에 있는 편의를 잃으므로, 13일짜리 프로젝트에서는 **그냥 Route 53으로 두는 편이 낫다.**

## 4. 절차

### 4-1. 등록

1. AWS 콘솔 → **Route 53** → **Registered domains** → **Register domains**
2. 이름 검색 → 두 개를 장바구니에 담는다 (한 번에 결제 가능)
3. 기간 **1년**, **자동 갱신은 필요 여부를 판단해 설정한다**
   - 켜두면 1년 뒤 자동 결제된다. 계속 쓸 게 아니면 끈다
4. 등록자 연락처 입력 — **개인정보 보호(Privacy protection) 켜기**
5. 결제

### 4-2. ⚠️ ICANN 이메일 인증 — 이걸 놓치면 프로젝트가 멈춘다

등록 직후 등록자 이메일로 **확인 메일**이 온다.

| | |
|---|---|
| 기한 | **TLD에 따라 3~15일** |
| 놓치면 | ICANN 규정에 따라 **도메인이 정지된다** (상태: `ClientHold`) |
| 정지되면 | **DNS가 전혀 응답하지 않는다.** 사이트가 통째로 죽는다 |
| 복구 | 링크를 누르면 자동 해제되지만, 그 사이 시간은 날아간다 |

> **13일짜리 일정에서 도메인 정지는 회복이 안 된다.**
> 등록 직후 **메일함과 스팸함을 즉시 확인하고 링크를 누른다.** 이걸 오늘 안에 끝낸다.
> 메일이 안 오면 Route 53 콘솔에서 재발송할 수 있다.

### 4-3. 호스팅 영역 확인

등록이 완료되면 같은 이름의 **호스팅 영역이 자동 생성**된다.
Route 53 → Hosted zones 에서 두 개가 보이는지 확인한다.

### 4-4. A 레코드 (EC2 준비 후)

EIP를 할당한 뒤 레코드 3개를 만든다.

| 호스팅 영역 | 레코드 이름 | 유형 | 값 |
|---|---|---|---|
| `<SHOP_DOMAIN>` | `lp` | A | `<EIP>` |
| `<SHOP_DOMAIN>` | `app` | A | `<EIP>` |
| `<TRACK_DOMAIN>` | `api` | A | `<EIP>` |

TTL은 **60초**로 둔다. 초반에 IP를 바꿀 일이 생기면 기본값(300초)은 답답하다.

---

## 5. 검증

```bash
# 세 줄이 모두 같은 EIP를 뱉어야 한다
dig +short lp.<SHOP_DOMAIN> app.<SHOP_DOMAIN> api.<TRACK_DOMAIN>

# 등록 상태 — ClientHold 가 보이면 ICANN 인증이 안 된 것이다
whois <SHOP_DOMAIN>  | grep -i "status\|registrar"
whois <TRACK_DOMAIN> | grep -i "status\|registrar"
```

| # | 확인 | 통과 기준 |
|---|---|---|
| 1 | Route 53 콘솔의 도메인 상태 | 두 개 모두 정상 등록 |
| 2 | **ICANN 이메일 인증 완료** | `ClientHold` 없음 |
| 3 | 호스팅 영역 2개 생성됨 | Hosted zones 목록 |
| 4 | `dig` 결과가 같은 EIP | 세 호스트 모두 |
| 5 | WHOIS 프라이버시 적용 | 개인 주소·전화가 노출되지 않음 |

> **DNS 전파가 끝나기 전에는 [setup.md](setup.md) 4장(ACME)으로 넘어가지 않는다.** DNS가 안 된 상태로 Caddy를 올리면 인증서 발급이 실패하면서 Let's Encrypt 발급 한도만 소모한다.

## 6. 등록 후 알아둘 것

| 항목 | 내용 |
|---|---|
| 이전 잠금 | 신규 등록 도메인은 **60일간** 다른 등록기관으로 이전할 수 없다 (ICANN 규정) |
| 환불 | 도메인 등록은 원칙적으로 환불되지 않는다. 철자를 반드시 확인하고 결제한다 |
| 자동 갱신 | 기본 켜짐. 1년 뒤 결제를 원치 않으면 등록 직후 끈다 |
| 삭제 | 도메인은 등록 기간이 끝나야 사라진다. 호스팅 영역만 지우면 DNS 과금은 멈춘다 |

## 7. 결정 기록

| 항목 | 값 | 근거 |
|---|---|---|
| 등록기관 | AWS Route 53 | EC2와 같은 콘솔. 13일 일정에서 도구를 늘리지 않는다 |
| 도메인 수 | **2개** | [ADR-002](decisions/ADR-002-two-registered-domains.md) |
| TLD | **`.com`** (양쪽) | 위 2장 — TLD 평판이 실험 변수가 되는 것을 막는다 |
| 기간 | 1년 | 최소 단위 |
| 프라이버시 | 켬 | 무료. 개인 주소가 WHOIS에 공개되는 것을 막는다 |
| DNS | Route 53 호스팅 영역 | 호스팅 영역 비용(연 $12)을 감수하고 단순함을 택한다 |

실제 구입한 도메인 이름과 날짜는 [worklog.md](worklog.md)에 기록한다.
