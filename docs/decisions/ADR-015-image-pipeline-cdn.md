# ADR-015 · 이미지 파이프라인과 CDN

**상태**: 확정 (2026-09-08) · **Phase 2** (서류 지원 이후)

## 배경

[ADR-014](ADR-014-stack-alignment.md) 정렬표에서 이미지 파이프라인은 **"포기"** 로 분류돼 있었다. 시간과 비용 때문이었다.

그런데 두 가지가 이 판단을 뒤집는다.

**① 웹툰 서비스에서 이미지는 곁다리가 아니라 본체다.** 회차당 이미지가 수십 장이고, 트래픽의 대부분이 정적 자산이며, **CDN 비용이 곧 사업 비용**이다. 이걸 빼면 "웹툰 도메인을 다뤘다"는 말이 절반만 참이 된다.

**② 미경험 영역이라 오히려 값이 크다.** CDN을 안 써봤다면, 써보는 것 자체가 면접에서 할 말이 된다. 그리고 인프라 포지션(#3)에도 직결된다.

관측된 대상 조직 구성:

```
thumb.<도메인>  →  img-<서비스>.<국내CDN>  →  S3 (x-amz-version-id: 버저닝 켜짐)
Cache-Control: public, max-age=2592000   (30일)
경로: /upload/contents/{YYYYMMDD}_{hash}/{회차}/{timestamp}.jpg
```

## 결정

**S3(버저닝) 오리진 + CloudFront**로 구성한다. Phase 2에서 만든다.

| 계층 | 선택 | 대상 조직과의 관계 |
|---|---|---|
| 오리진 | **AWS S3**, 버저닝 켬 | **그대로** |
| 배포 | **CloudFront** | 타협 — 대상은 국내 CDN |
| 캐시 | `public, max-age=2592000` | **그대로** |
| 경로 | 날짜 + 해시 + 회차 + 타임스탬프 | **그대로** — 교체 시 URL이 바뀌어 무효화가 불필요해진다 |
| 접근 제어 | **Origin Access Control** (S3 직접 접근 차단) | 대상은 미확인 |

### CloudFront를 택한 이유 (국내 CDN 대신)

| | |
|---|---|
| AWS 계정 안에서 끝난다 | 별도 계약·심사 없음 |
| 프리티어가 있다 | 학습 규모에서는 사실상 무료 |
| 학습 자료가 많다 | 미경험 영역이라 이게 중요하다 |
| **국내 CDN은 대개 사업자 계약이 필요** | 개인이 붙이기 어렵다 |

> 정렬 원칙상 "타협"이다. **왜 국내 CDN을 안 썼는지**를 이 문서로 남긴다.
> 그리고 국내 CDN을 쓰는 이유(한국 트래픽 지연·비용)는 아는 상태로 둔다.

## 진짜 학습 대상

CDN을 "붙이는 것"은 반나절이다. **값은 그 다음에 있다.**

| 주제 | 왜 어려운가 |
|---|---|
| **캐시 키 설계** | 무엇을 키에 넣느냐가 적중률과 사고를 동시에 결정한다 |
| **`Vary` 처리** | 오리진 반향 헤더 + `Vary` 누락 = **캐시 포이즈닝** |
| **개인화와 캐시의 분리** | 개인화 필드가 섞이면 `private`밖에 못 쓴다 |
| **무효화 비용** | CloudFront invalidation은 **건당 과금**이다. 그래서 경로에 타임스탬프를 넣는다 |
| **서명 URL** | 유료 회차를 URL 추측으로 못 열게 |
| **압축·포맷 협상** | `Accept: image/webp` 분기와 캐시 폭발의 트레이드오프 |

> **경로에 타임스탬프를 넣는 것과 무효화를 호출하는 것은 같은 문제의 두 해법이다.**
> 대상 조직은 전자를 택했다(관측). 그게 왜 나은지 설명할 수 있으면 CDN을 아는 것이다.

## 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| 이미지 없이 진행 (초판) | 웹툰 도메인의 본체를 빼는 것 |
| S3만, CDN 없이 | S3 직접 서빙은 지연·비용 모두 나쁘다. **CDN이 학습 목표인데 빼면 의미가 없다** |
| 로컬 파일시스템 + OpenResty 서빙 | 정렬도 0. 클라우드 스토리지 경험이 남지 않는다 |
| 국내 CDN 계약 | 개인 계약이 어렵고 리드타임이 있다 |
| Phase 1에 포함 | 13일에 불가능. **서류에 필요한 것이 아니다** |

## 결과

- **Phase 2**. 서류 지원(09-19) 이후 착수한다
- **비용**: S3 + CloudFront 프리티어 범위. 이미지 용량이 작아 사실상 0
- **범위 한정**: 회차 이미지 서빙까지. **워터마크·DRM은 하지 않는다**
- **README에 명시**: "CDN은 CloudFront입니다. 대상 조직은 국내 CDN을 쓰는데, 개인 계약이 어려워 타협했습니다"
- **검증**: 캐시 적중률, 무효화 없이 이미지 교체, 서명 URL 만료 동작
