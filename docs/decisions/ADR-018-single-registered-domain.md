# ADR-018 · 등록 도메인 1개로 간다 ([ADR-002](ADR-002-two-registered-domains.md) 철회)

**상태**: 확정 (2026-09-12) — [ADR-002](ADR-002-two-registered-domains.md)를 대체한다

## 배경

[ADR-002](ADR-002-two-registered-domains.md)는 등록 도메인 2개를 "이 프로젝트에서 가장 중요한 결정"이라고 적었다. 근거는 타당했다 — 브라우저는 same-site를 eTLD+1로 판정하므로, 서브도메인만으로는 서드파티 쿠키 차단과 `SameSite=None`을 재현할 수 없다.

두 번째 도메인 등록은 두 번 실패했다(등록기관 거절). 다른 등록기관으로 사는 것은 가능했지만, **필요성이 충분히 설명되지 않는다는 판단**으로 사지 않기로 했다.

## 그래서 정확히 무엇을 잃는가

여기서 한 번 틀렸다. 나는 "크로스사이트 실험 전부"를 잃는다고 말했는데 **과대평가였다.**

수집 엔드포인트를 `api.sshwan.com`에 두면 `lp.sshwan.com` → `api.sshwan.com`은

- **same-site** — 등록 도메인이 같다
- **cross-origin** — 서브도메인이 다르다

**CORS는 오리진 기준이다.** 그래서 preflight도, `Vary: Origin`도, `Allow-Origin: *`와 credentials의 충돌도 **그대로 일어난다.**

| 실패 시나리오 | 도메인 1개에서 |
|---|---|
| B-2 `Allow-Origin: *` + credentials | ✅ 재현됨 (cross-origin) |
| B-3 `sendBeacon` 헤더 제약 | ✅ 재현됨 (cross-origin) |
| C-1 301 캐시 · C-2 리다이렉트 파라미터 유실 | ✅ 무관 |
| D·E (워커·복제·보존) | ✅ 무관 |
| **A-1 서드파티 쿠키 차단** | ❌ **불가** |
| **A-2 `SameSite=None` 필요성** | ❌ **불가** (same-site면 `Lax`로 충분하다) |

**10개 중 2개를 잃는다.** 앞서 4개라고 말한 것은 틀렸다 — CORS를 cross-site의 속성으로 잘못 묶었다.

공고 우대사항의 `Domain, Redirect, CORS` 중 **`Redirect`와 `CORS`는 그대로 증명된다.** `Domain`은 절반만 남는다(서브도메인 간 데이터 전달).

## 결정

1. **등록 도메인 1개**(`sshwan.com`)로 간다. 수집은 `api.sshwan.com`에 둔다
2. **서드파티 쿠키·`SameSite=None`에 대한 주장을 문서에서 내린다.** README·`failure-scenarios.md`에서 A-1·A-2를 결과 칸이 빈 채로 남기지 않고, **"하지 않기로 한 것"으로 옮기고 이유를 적는다**
3. **`TRACK_DOMAIN` 지원 코드는 남긴다.** 비워두면 동작하도록 이미 만들어 뒀고(CI가 두 경우를 모두 검사한다), 나중에 도메인이 생기면 `.env` 한 줄로 붙는다. 죽은 코드가 아니라 **휴면 경로**다

## 왜 주장을 내리는가

[ADR-002](ADR-002-two-registered-domains.md)에 미리 적어 둔 문장을 그대로 지킨다.

> **증거 없는 주장을 남겨두는 것이 도메인을 아끼는 것보다 훨씬 큰 손해다.**

README에 "서드파티 쿠키 차단을 브라우저별로 실측했다"고 쓰고 실측 표가 비어 있으면, 그 하나가 나머지 기록의 신뢰도까지 깎는다. **못 한 것을 못 했다고 적는 편이 낫다.**

## 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| 무료 서브도메인(`*.duckdns.org` 등)으로 두 번째 등록 도메인 흉내 | 공개 접미사 목록에 등재된 곳은 eTLD+1이 갈려 기술적으로는 성립한다. 그러나 **TLD·호스트 평판이 실험 변수가 된다** — 요청이 막혔을 때 `SameSite` 때문인지 도메인 평판 때문인지 구분할 수 없다 → [domain-setup.md](../domain-setup.md) 2장 |
| A-1·A-2를 "문서상 설명"으로 남김 | 실측 없는 설명은 검색으로 얻은 지식과 구별되지 않는다. 이 프로젝트가 파는 것은 그게 아니다 |
| `api.` 를 없애고 수집을 `app.` 에 합침 | 수집과 서비스를 한 호스트에 두면 CORS 자체가 사라진다. **cross-origin은 남겨야 한다** |

## 결과

- **감수**: A-1·A-2를 실측하지 못한다. 면접에서 서드파티 쿠키를 물으면 *"설계는 했고 왜 못 했는지 압니다"* 까지만 말할 수 있다
- **얻음**: 비용 0, 그리고 **못 한 것을 정확히 아는 상태**. 범위를 줄인 것이지 모르는 것이 아니다
- **얻음**: 남는 시간을 M4(아웃박스·GA4·커스텀 수집)와 실패 시나리오 결과 채우기에 쓴다
- **되돌리는 조건**: 추적 도메인이 생기면 `.env` 한 줄 + DNS + certbot. 코드는 이미 준비돼 있다
